# deadkeys

Type the keys a broken laptop keyboard can't. Hold CapsLock and press a
working key to send a dead one, or make a spare key always type it.
Windows only.

```
npx deadkeys
```

This downloads `deadkeys.exe` from the matching
[GitHub release](https://github.com/Visalan-H/Keyboard-issue-lenovo/releases),
checks its SHA-256, and starts it in the tray. Files live in
`%LOCALAPPDATA%\DeadKeys`. Run the command again to open the settings page.

Full docs: https://github.com/Visalan-H/Keyboard-issue-lenovo#readme
