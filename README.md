# DeadKeys

Type the characters your broken laptop keys can't.

Some keys on this ThinkPad E15 keyboard stopped working (`2 W S X` and `O 9`).
That is a hardware fault in the keyboard matrix, so no driver can bring them back.
DeadKeys lets other keys type the missing characters instead:

- **Layer rules:** hold CapsLock and press a working key, e.g. CapsLock + Q types `W`.
- **Direct remaps:** a key you never use always types a dead one, e.g. Insert types `S`.

Work in progress. Windows only.
